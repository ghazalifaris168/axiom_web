# axiom_web
**AXIOM** is a completely free, open-source educational platform designed for **Cambridge International AS & A Level students**. AXIOM provides comprehensive study materials, topical questions, and classified past papers—without any paywalls.
# Features
- Comprehensive **study and revision notes** for AS & A Levels materials
- Variants of **past exam papers** with official marking schemes
- Topical practice: **Questions organized by spesific syllabus chapters**
- **100% free**: No hidden/locked materials, past papers, questions, etc.
